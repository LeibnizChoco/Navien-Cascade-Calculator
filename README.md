# 웹 계산기

웹 브라우저에서 실행되는 완전한 기능의 계산기 프로그램입니다.

## 기능

- **기본 연산**: 덧셈(+), 뺄셈(-), 곱셈(×), 나눗셈(÷), 나머지(%)
- **소수점 계산**: 소수점이 있는 숫자 계산 지원
- **키보드 지원**: 숫자 키, 연산자 키, Enter(=), Backspace(DEL), Escape(AC) 지원
- **반응형 디자인**: 모바일과 데스크톱에서 모두 사용 가능
- **현대적인 UI**: 그라데이션 배경과 글래스모피즘 효과

## 사용법

1. `index.html` 파일을 웹 브라우저에서 열기
2. 마우스로 버튼 클릭하거나 키보드로 입력
3. 계산 결과 확인

## 키보드 단축키

- **숫자 키 (0-9)**: 숫자 입력
- **연산자 키**: +, -, *, /, %
- **Enter 또는 =**: 계산 실행
- **Backspace**: 마지막 문자 삭제
- **Escape**: 모든 내용 지우기
- **소수점**: . 키

## 파일 구조

```
calculator/
├── index.html      # 메인 HTML 파일
├── styles.css      # 스타일시트
├── script.js       # JavaScript 로직
└── README.md       # 프로젝트 설명
```

## 기술 스택

- HTML5
- CSS3 (Grid, Flexbox, 반응형 디자인)
- Vanilla JavaScript (ES6+)

## 브라우저 지원

- Chrome (권장)
- Firefox
- Safari
- Edge

## 실행 방법

1. 모든 파일을 같은 폴더에 저장
2. `index.html` 파일을 더블클릭하여 브라우저에서 열기
3. 또는 로컬 서버를 사용하여 실행

## 커스터마이징

사용자가 지정한 로직으로 값을 출력하는 기능을 추가하려면 `script.js` 파일의 `calculate()` 함수를 수정하거나 새로운 함수를 추가하면 됩니다.
